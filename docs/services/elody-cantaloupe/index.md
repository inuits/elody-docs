# Elody Cantaloupe

The [Cantaloupe](https://cantaloupe-project.github.io/) image server, packaged for Elody. It serves the [IIIF Image API](https://iiif.io/api/image/): tiles, crops and scaled versions of the stored images. The [media viewers](/services/elody-frontend/features/media-viewers) load them through the GraphQL service's `/api/iiif/*` proxy.
