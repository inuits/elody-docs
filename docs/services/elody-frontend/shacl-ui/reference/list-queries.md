### List Query

`elody:ListQuery`: The entities document a list element loads, with its filters document: the result fragment per type (without results the entities document stays hand-written and only the filters document is generated) and the scoping filters (the type, the relation to the entity shown). Named by elody:queryName; the filters document by elody:filtersQuery, else the query name with Filters.

Declared under `elody:listQuery` of [Entity Ui](./entity-ui.md#entity-ui), `elody:taggingQuery` of [Property Shape](./properties.md#property-shape), `elody:listQuery` of [Element](./detail-page.md#element), `elody:listQuery` of [App](./app.md#app).
