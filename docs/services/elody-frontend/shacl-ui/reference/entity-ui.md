### Entity Ui

`elody:EntityUi`: The UI of one Elody entity type. It is a sh:NodeShape (R1): its sh:property shapes are the one list of fields that drives the listing card, the detail panels, the sort options and the forms. sh:targetClass anchors it to the domain ontology. No standard term: shui describes forms, not listings and detail pages.
`elody:EntityUi`: The UI of one Elody entity type.
