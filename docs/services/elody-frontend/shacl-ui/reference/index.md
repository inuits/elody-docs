## Terms on any node

| Term | Type | Meaning |
|---|---|---|
| `elody:alias` | `xsd:string` | The GraphQL alias under which a filter (a filter without one is emitted unaliased), action, panel, element, form tab (on an elody:Form; default "name"), submit action (on an elody:submit node; default "createAction") or property is emitted. On a property shape: the field name the fragment reads the value under when it is not the metadata key (title: keyValue(key: "email")); several property shapes may share one sh:path under different aliases. Open string by design. |
| `elody:can` | `xsd:string` | A fine-grained permission string ("update:pipeline:has-runner"). On a bulk operation or a list element: the permissions it needs; on a panel: the permission editing it needs (can(input: "update:feedback")). Open string: permissions are client-defined. |
| `elody:collapsed` | `xsd:boolean` | The element or panel starts collapsed. |
| `elody:config` | a [Config Entry](./entity-ui.md#config-entry) node | A configuration entry of a view mode or a map element. |
| `elody:customBulkOperations` | a [Custom Bulk Operations](./bulk-operations.md#custom-bulk-operations) node | A named operation set (on an EntityUi: declares it; on a list element: uses it, as a node reference). |
| `elody:element` | a [Element](./detail-page.md#element) node | An element in the column; on an elody:Panel, a list element shown among the panel's fields (a panel holding a filtered list of related entities): its sh:order is its position among the panel's items, fields and elements together, counting from 1. |
| `elody:elementSpread` | `xsd:string` | On a column: the name of a shared fragment on EntityViewElements spread among the column's elements (...entityHistoryVersionList). |
| `elody:endpointMethod` | `xsd:string` | The HTTP method of the call (endpointMethod: POST). |
| `elody:endpointUrl` | `xsd:string` | The API path a custom menu action calls (doCustomAction: endpointUrl), with $id for the entity. |
| `elody:field` | `rdfs:Resource` | A field shown in a panel or an overview, referenced by the sh:path IRI of the EntityUi's property shape (R3). On a form source: the resolver field, as a string (see elody:formSourceField). |
| `elody:filter` | a [Filter](./filters.md#filter) node | A filter of a listing (EntityUi) or a picker. |
| `elody:filtersQuery` | `xsd:string` | Operation name of a listing's, a picker's or a list query's filters document, when it is not the query name with Filters. |
| `elody:filtersType` | `xsd:string` | On a list query or picker: the GraphQL type its filters document narrows to (EntityTypeFilters { ... on QuestionInstance { advancedFilters { ... } } }). Without it the filters are selected on EntityTypeFilters itself. |
| `elody:form` | a [Form](./forms.md#form) node | The form an action, a modal or a flow step opens, as a node (R3): the generator derives the document name. Replaces the string references elody:formQuery and elody:createForm. An EntityUi lists its forms with the same property. |
| `elody:formSourceRef` | a [Form Source](./forms.md#form-source) node | The runtime form source an action opens, as a node (processor config forms). |
| `elody:fragment` | `xsd:string` | The name of a GraphQL fragment (a family's card, a picker result). Directive: derivable from the node. |
| `elody:fragmentName` | `xsd:string` | The GraphQL name of a shared fragment (basicCreateWorkFields, workTitleDataWindowElement, workTitleDataIntialValues). |
| `elody:graphqlType` | `xsd:string` | The GraphQL object type this UI (or picker result) is rendered for. Directive: it will be derived from sh:targetClass through the application profile's class-to-type register. |
| `elody:icon` | `xsd:string` | A DamsIcons name. Open string: the icon set is the platform's and grows. |
| `elody:key` | `xsd:string` | A platform key: a config entry's name, a filter's document key, a step's key, a card field's value key when it differs from sh:name. |
| `elody:labelKey` | `xsd:string` | The Elody translation key under which the label is shown. The label text itself is sh:name (property shapes) or rdfs:label (property groups), language-tagged; `generate` writes those texts into the client's translation bundles under this key. Without elody:labelKey the generator mints ui.&lt;type&gt;.&lt;key&gt;. No standard term: SHACL carries label texts, not an application's translation keys. |
| `elody:listing` | a [Entity Ui](./entity-ui.md#entity-ui) node | On a list query's or picker's result: an EntityUi with elody:emit "inline" whose listing (values, card, view modes) is rendered inside the result (... on Person { intialValues { ... } teaserMetadata { ... } }) instead of, or next to, a fragment spread (elody:fragment). |
| `elody:listQuery` | a [List Query](./list-queries.md#list-query) node | The declared entities and filters documents the list loads; sets customQuery and customQueryFilters. On an EntityUi: list queries the type's documents name without a list element (the documents of the delete flow), and the type's orphan documents, an entities or filters document nothing references but the client keeps; a filters document alone names only elody:filtersQuery. |
| `elody:multipleColumns` | `xsd:boolean` | The panel (or property group) may lay its fields out in several columns (canBeMultipleColumns). |
| `elody:parentFilterKey` | `xsd:string` | On a filter: the parentKey argument of a selection filter ("relations"). On a comments element: the filter key that ties comments to this entity. |
| `elody:picker` | a [Picker](./list-queries.md#picker) node | A picker, as a node (R3): on an EntityUi it is declared; on a flow step or list element it is used. Replaces the string pairs pickerQuery/pickerFiltersQuery and pickerList/pickerFilters. |
| `elody:queryName` | `xsd:string` | The GraphQL operation name of a form, flow, picker, custom bulk operation set or form source. Optional: the generator derives it from the node's local name when absent (R3). |
| `elody:readsHost` | `xsd:boolean` | On a property shape: true reads the value relative to the entity the list is shown on (the keyValue takes uuid: $userUuid). On a list query or picker: the document declares $userUuid: String! (derived too from a result listing that reads the host). Default false. |
| `elody:relationType` | `xsd:string` | An Elody relation type name (hasProcessor, isRunnerFor). Open string: client-defined, convention has&lt;X&gt; / is&lt;X&gt;For. On a property shape it names the relation the property reads and writes; without it, sh:path ex:x with sh:class is has&lt;X&gt; and sh:path [ sh:inversePath ex:x ] is is&lt;X&gt;For, the mirror collection-api stores on the other entity. |
| `elody:showAsButton` | `xsd:boolean` | true shows the menu action as a button of its own (showAsButton). |
| `elody:showTooltip` | `xsd:boolean` | Show the platform tooltip on a filter. Replaces the boolean use of the retired elody:tooltip; the tooltip text of a property is sh:description. |
| `elody:spread` | `xsd:string` | A hand-written fragment on WindowElementPanel spread into the panel, after its fields (...entityAuditMetadata). |
| `elody:submitAction` | `xsd:string` | What the form's submit does (actionType: submit, ocr, submitWithUpload). Default submit. |
| `elody:tooltipKey` | `xsd:string` | The translation key of the tooltip shown with a panel or form field (tooltip(input: ...)). |
| `elody:value` | `rdfs:Literal` | A config entry's value: string, number, boolean, an RDF list of strings, a node holding elody:config entries (an object value), or an elody: enumeration instance (rendered as its enum value, e.g. elody:WktMap). On an elody:FilterOption: the option's value. |
| `elody:viewMode` | a [View Mode Selection](./entity-ui.md#view-mode-selection) node | An allowed view mode of the listing (EntityUi or ListingUi). |
