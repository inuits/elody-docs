# Elody Collection

The Flask REST + GraphQL API backing entity storage, filtering, and
relations.

## Features

- [Advanced Filtering](advanced-filtering.md) — filter entities by type,
  property, and relation, with matchers, facets, and count handling.
- [Policies & Permissions](policies-and-permissions.md) — role-based
  create/read/update/delete rules, object and key restrictions, and how
  policies are wired.
