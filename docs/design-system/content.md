# Content & language

The Elody interface is available in English, Dutch and Arabic. All interface
text comes from translation files, never from text written into a component,
so every label can be translated.

These docs use the English text.

## Writing style
- **Sentence case** for everything: buttons, labels, headings, menu items.
- **Buttons are verbs** that say what happens: "Save", "Add person",
  "Open record". Avoid "OK" and "Yes".
- **Labels are nouns**, without a colon: "Title", "Date of birth".
- **Be short.** The interface is dense; every word should earn its place.

## Common texts
| Situation | Text |
|---|---|
| Empty value | "No value" |
| Required field missing | "{Field} is required" |
| Save / cancel | "Save" / "Cancel" |

## Errors
Say what went wrong and how to fix it, in the place where it happened: next to
the field, not only in a notification.

## Placeholders
A placeholder shows an example of what to enter. It never replaces the label,
because it disappears as soon as you type.
