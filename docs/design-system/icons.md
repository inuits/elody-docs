# Icons

Elody uses the [Unicons](https://iconscout.com/unicons) line icon set. Only
icons registered in the interface can be used, so every screen draws from the
same set.

## Rules
- An icon supports a label; it rarely replaces one. Icon-only buttons are for
  well-known actions (close, zoom, more actions) and always have an
  accessible name.
- Give an icon the colour of the text it sits with, unless it marks a state
  (error, success).
- Use one icon for one meaning everywhere: the same icon never stands for two
  different actions.
- Hide decorative icons from screen readers.
