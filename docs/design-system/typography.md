# Typography

Elody uses **Lato** in three weights: regular, bold and black. The interface is
dense, so most text is small. Field values are the main reading size.

<StoryEmbed id="foundations-tokens--type" title="The type scale with each size's use" height="440px" />

## Type scale
| Token | Use |
|---|---|
| `--text-micro` | badges, tiny chips. The smallest size allowed. |
| `--text-hint` | hints, counts |
| `--text-label` | field labels, column headers, chips, small buttons |
| `--text-ui` | buttons and header controls |
| `--text-table` | table cells, menu items, options |
| `--text-value` | field values and input text: the reading size |
| `--text-heading` | headings |
| `--text-title` | page titles |

Weights: `--weight-regular`, `--weight-bold` and `--weight-black`.

## Rules
- Use sentence case everywhere: "Add person", not "Add Person".
- Don't use uppercase for labels or headings.
- Nothing is smaller than `--text-micro`.
- Show hierarchy with size and weight, not colour alone.
